# Luyao Wang Academic Homepage V42

Publication years now have a small calendar icon and a subtle year marker. The right-edge full-height color rail is harmonized with the overall sage/teal palette: muted yellow-green to teal for Journal, and slate blue to soft violet for Conference. The rest of the V41 site is preserved.

Deploy by uploading all files/folders to the repository root and enabling GitHub Pages under Settings → Pages → Deploy from a branch → main → /(root).
